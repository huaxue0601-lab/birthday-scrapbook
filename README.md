# Birthday scrapbook

A paper collage birthday experience: opening gift, instant camera, birthday toast,
film memories, Wuhan–Bangkok map, boarding pass, flight heart, scratch card and
heart slot machine.

Static HTML/CSS/JavaScript. Entry: `index.html`.
Run locally: `python3 -m http.server 8766 --bind 127.0.0.1`.
GitHub Pages can publish directly from the root of the `main` branch.

Childhood portraits, three film memories, three Bangkok photographs and a birthday card are included.
Photographs persist across reloads and open in a full-image viewer. Six gift vouchers are configured; replay does not add new vouchers. The final letter remains blank.

Map geography: Natural Earth public-domain data, https://www.naturalearthdata.com/.
